# notes/

**Everything else in this directory is gitignored.** This README is the only file that travels with the repo.

## Purpose

Personal scratchpad for the repo owner. Distinct from `docs/scratch/` (which is for in-progress *work artifacts*) — this is for *meta* notes: TODO-for-next-session reminders, references to read later, half-formed product thoughts, command snippets.

## Why two directories?

- `docs/scratch/` — work-in-progress that might become durable docs (review outputs, design sketches, draft sections of the spec)
- `notes/` — anything else; lives outside the `docs/` tree so it doesn't accidentally suggest itself as documentation

Both are gitignored. The distinction is intent, not enforcement. Use whichever feels right.
